# Product Overview

## What this is
Creative Finance Deal Desk OS is a qualification and routing engine for a
creative-finance real estate business. It captures leads, scores them,
schedules follow-up, matches sellers and buyers, and hands qualified deals to
closers.

## What it is not
- Not a lender
- Not a law firm
- Not a closing company
- Not a title company

## Operating pipeline
LEAD -> CONTACT -> QUALIFY -> SCORE -> FOLLOW-UP -> MATCH -> PACKAGE -> ESCALATE

## Users
- Intake agents
- Follow-up agents
- Closers / deal leads
- Ops / admin

## Outputs
- Machine-readable JSON envelopes for every workflow
- Outreach scripts for SMS, email, and call
- Closer packets in markdown
